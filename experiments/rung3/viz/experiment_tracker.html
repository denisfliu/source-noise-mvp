Theme 1 — Does the pin mechanism work? (core factorization)

Low-data ladder: where the advantage lives RESULT

  • Transits with the pin are 20/20 from 3 demonstrations per task upward; the no-pin arm manages 10–14/20 through 40 demos/task and completes zero tasks there.
  • Completions cross: at 60 demos/task the no-pin arm catches up (transits tie 20/20; completions 13/20 vs 9/20, not significant at n=20). At ~100 the pin system reaches 19/20.
  • Earlier claim corrected: "the no-pin arm completes zero tasks at any size" was generalised from the 3/10/40 rungs and is false at 60.

LEARNED — the factorization buys competence in the data-starved regime and its advantage decays as data grows, reproducing the LIBERO conditional (structure helps only when the policy is the bottleneck) as a located crossing point on a single curve.

Grounded command source without a task list RESULT

  • c = MLP([state, PCA of the post-fusion language-token embedding]); no task list, classifier, or string matching. 13/20 completions vs 19/20 for the string-matched scaffold on the same flow; clearance is the weak axis.
  • Measured limit: with four prompts the language subspace is exactly 3-dimensional (PCA keeps 100% of it), so the interface is enumeration-free while the data is not. Held-out paraphrases fly the left gate as well as the trained prompt (3/5) and collapse on the right (0/5).
  • Paraphrase augmentation raised every offline metric (c-R² 0.939 → 0.962) and lowered closed-loop success (13/20 → 5/10) — a fifth instance of offline gains not transferring.
  • Latching the embedding buys nothing measurable (10/20 live vs 13/20 latched, n.s.) and breaks multi-stage instructions, so live embeddings are now the default.

LEARNED — grounding the command in language works well enough to complete tasks, and its remaining gap is precision, not task identity. Paraphrase robustness needs more distinct tasks, not more wordings of four.

Mechanism decomposition (component battery + zero-pin control) RESULT

  • Additive control (scratch flow + post-hoc coarse overwrite, same oracle c): matches the pin flow on transits and completions at n160 but clearance collapses (4/10 vs 10/10, clips to 0.002 m) — the coarse channel steers largely algebraically; pin training buys complement coherence.
  • Zero-pin control (source orthogonalized exactly like the pin but c = 0 — consistent noise, no answer, no channel): 0/10 transits at n12, vs pin 10/10 and scratch 6/10 — source consistency alone buys nothing.
  • Demo-oracle execution ceilings: record 10/7/10 (transit/full/clean per 10); n12 8/0/4 — under perfect commands, goal-phase execution and cleanliness are the data-hungry components; transit steering is nearly free.

LEARNED — the low-data advantage is the supplied coarse answer, not source familiarity; the channel is identity by construction; training with pins makes the residual detail cooperate with the command.

Theme 2 — What should c be? (basis U and target design)

Basis selection RESULT

  • RRR (subspace predictable from state+language) beats PCA in every multi-task LIBERO regime at equal coverage.
  • U anatomy: net-displacement 4-space (principal angles 3.7–14°) + a yaw-ramp timing mode; <0.2% energy above DCT mode 2; c decodes linearly to meters.

LEARNED — the useful coarse code is the observation-predictable subspace; it is interpretable (displacement + timing).

Learning U end-to-end NEGATIVE

  • Learnable orthonormal U + prediction head, trained jointly with the flow (λ=1): 1/5 directions near the displacement space; the rest high-frequency, yaw-dominant.

LEARNED — the flow loss prefers pinning components it predicts worst (fine detail); a coarse factorization requires explicit structure (RRR) or stronger predictability pressure.

Domain dependence of U MEASURED

  • Real vs synthetic RRR bases: shared ~3-dim displacement core (6–26°), two divergent directions (47–61°); real basis tilts away from pure displacement; real-chunk coordinates only partially transportable (|corr| 0.45–0.95).
  • Per-embodiment (earlier arc): invariance-selected bases transfer across arms (GLAP 0.75 vs PCA 0.34); variable-DOF transfer fails because the pin partly captures realization.

LEARNED — U is body- and domain-dependent beyond a shared displacement core.

Per-domain U NEGATIVE

  • Bases refit with one recipe (ridge λ=10, K=5) and authoritative labels: real vs clean-synth bases share ~1–2 directions (5.9°, then 40–83°); pooled stays within 10° of the deployed basis in 4 of 5 directions.
  • Held-out REAL c-R² of the prior, the deployment-relevant number: real basis + real data 0.50; deployed synth basis + real data 0.69; pooled basis + pooled data 0.69; deployed basis + pooled data 0.72 (best). The real basis's later directions are barely state-predictable (per-dim tail 0.18/0.16).
  • Real chunks are harder to predict in any basis (best 0.72 vs 0.97 on synth) — a data property, not a basis mismatch.

LEARNED — refitting U per domain does not improve command predictability; the RRR objective (feature-predictable chunk variance) selects real-data directions the state prior cannot predict. Deployed basis retained; the contingent closed-loop retrain is cancelled.

c precision requirements MEASURED

  • c ≈ g(pose) with g near-isometric: command error ≈ pose error. Gate aperture tolerance ~±5 cm.
  • c is 99% state-driven in this data (language ~1%).

LEARNED — c is low-dimensional and predictable but not error-tolerant: it encodes metric geometry, so the precision burden of the task sits in the coarse channel. Motivates queue #5 (target re-parameterization) and trust calibration (Theme 3).

Theme 3 — Command-error tolerance (soft pin, σ)

Soft pin on LIBERO RESULT

  • Training with c + σ·std·ε (σ=0.7): closed-loop with VLM-predicted c goes 0.00 → 0.87.

LEARNED — a flow trained only on exact pins executes command errors; injecting command noise in training teaches correction.

VLM-error-matched soft pin (covpin) NEGATIVE

  • Record-recipe flow trained with pin noise ~ N(mean, Σ) from the union head's measured error distribution (per-dim ratios 0.25–0.39 of a std, cross-dim correlations to ±0.51; the mean is negligible at 0.02–0.06 std).
  • Battery vs the isotropic references, same command sources: state prior — left 0/5 transit (4/5 reach the gate region but never cross clean) vs 8–9/10 full for the hard-pin and σ=0.35 flows; right 5/5 transit, 0 full. Union head — right 2/5 transit vs 4/5 on the σ=0.35 aug flow.

LEARNED — error-shaped (correlated) pin noise is worse than isotropic at comparable magnitude. Working hypothesis: the head's errors correlate with task-relevant command directions, so tolerating that noise trains the flow to ignore the subspace where commands differ — selective degradation, not uniform softening. Theme 4 — Predicting c from observation (the command source)

Joint training + gradient routing (in-checkpoint command head) ACTIVE

  • Root cause of the grounded source's 0/10: the prior consumed features from a different checkpoint than it was fitted on (fine-tuning moves 18–22% of embedding dims >3σ). Re-pairing alone: left 0/5 → 10/10 clean, no retraining. Structural fix: the head lives INSIDE the flow checkpoint, so mispairing is impossible by construction.
  • Coupling axis (10 trials/side, strict = judge + clearance): B1 detached — right 7/10, left shaves the post (0.13–0.17 m). B2 coupled λ=1 — left 10/10 strict, right 0/10 transit. λ=0.3 — left 10/10 strict AND right 10/10 clean transit (clearances 0.31–0.38, demo-level), but 3/10 strict on right: flights overshoot the hover box by 0.1–0.6 m. Partial coupling recovers the right ROUTE; the endgame (no stop) is the remaining failure.
  • More optimisation hurts or is neutral: b1long (15k annealed) lost the right gate 7/10 → 0/5; adding state to the head (B1s) worse everywhere.
  • RRR-from-VLA claim re-verified as a clean 2×2 on 3 unseen-task LIBERO splits: the VLM-feature PREDICTOR is the win (+0.2..+0.4 vs one-hot −3.4..−3.8); the basis is a wash (RRR≈PCA here). Unseen language goals still weak.
  • Now completing the routing 2×2 with C2 (VLM trained by c loss only; flow loss provably detached — forward identical, VLM grad exactly 0) and C1 (VLM frozen; pairing cannot drift).

LEARNED — the feature-source pairing, not the architecture, killed the grounded command source; and WHICH losses reach the VLM decides which gate works. Coupling strength is a real dial: λ=0.3 is the first enumeration-free source to transit both gates 10/10 clean.

State-based priors RESULT

  • MLP on (state, task): held c-R² 0.96–0.97; carries the 39/40 record. Progress clock removed after it caused a settle failure; duration knowledge rejected as an input.
  • Weakness: large c2 errors at episode tails on-manifold; goal-phase completion is the recurring residual on aug/soft flows.

VLM-feature heads: the offline/closed-loop gap EXPLAINED

  • Deterministic maps on fused features: offline c-R² 0.92–0.96, closed-loop 0/N repeatedly.
  • Basin probe (new instrument): feedback gain vs perturbation radius. Prior gain grows with deviation (0.39→0.73 at 1 m); feature-map gain decays (0.23→0.11). Stability basin ≈ data tube (~0.3 m).
  • Pose decomposition: pooled features localize to 0.14–0.20 m; cascade (prior fed feature-estimated pose) shifts the command field 0.21 m; direct feature heads sit at 0.54 m → ~0.21 m information limit + ~0.33 m fitting error.
  • Jitter: feature heads 1.5–2.5× the prior's command jitter; for CFM heads it is sampling noise; k=8 mean + EMA(0.5) removes it at no accuracy cost.

LEARNED — offline R² does not measure closed-loop viability. The gap decomposes into basin width (data coverage), pose information (feature quality), and jitter (removable). Standing instruments: basin probe, disagreement probe, jitter measurement.

Attention readout over VLM tokens RESULT

  • 4 learned queries over 34 structured tokens (4×4-pooled patch grid per camera + text + global) vs mean pooling: held on-route c-R² 0.912 vs 0.905; basin gain at 1.0 m y/z 0.93/0.72 — not a clean win on any instrument.

Coverage experiments RESULT

  • Fat tube only (return-to-route labels, ±1 m offsets): basin gain at 1 m 0.05→0.70, but on-route R² dropped to 0.79 and closed-loop was 0/20.
  • Union (on-route + tube): R² restored (0.905), basin held, and the feature-only head achieved 4/5 right-scene transits — first reliable transits with no state input and no task one-hot.

LEARNED — coverage must be added to on-route data, not substituted for it; with coverage, features alone can command transits. Tube construction is a small-data patch; at scale, coverage should come from data diversity.

Hybrid (state ⊕ features) heads NEGATIVE

  • Concat hybrids underperform both parents across flows (union hybrid 1/5 vs feature-only 4/5).
  • Disagreement probe: image-only input change moves the command ~85% of the full response; state-only ~45% — the feature channel dominates. Consistent-perturbation probes miss this.

LEARNED — concatenation assigns authority by gradient dynamics, not information quality; the state pathway needs architectural priority (queue #4).

Two-stage flow matching for c RESULT

  • CFM head on (state, one-hot): closed-loop parity with the deterministic prior (L 5/5, R 4/5 full).
  • CFM on fused features: offline parity (0.911 vs 0.926); same-frame prompt change moves sampled c along the true behavioral axis (cos 0.983, 870 pairs) — language input is used.
  • Compound route: sampled heads reproduce the same wide-crossing as regression heads — mode averaging is not the compound failure mechanism. No off-manifold uncertainty signal (spread does not inflate).
  • Hybrid CFM produced one full strict success (right scene) from a language-grounded source — first such completion.

LEARNED — a generative stage-1 is viable and language-responsive but does not by itself fix accuracy, coverage, or compound behavior; sampling adds removable jitter.
